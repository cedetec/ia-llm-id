## Instrucciones

Realice las tareas utilizando el asistente de forma autónoma.

Para cada tarea se registra:

- si logró completarla;
- el tiempo empleado;
- si necesitó ayuda;
- observaciones relevantes.

Al terminar las tareas, responda cada afirmación utilizando la siguiente escala:

1 = Muy en desacuerdo
2 = En desacuerdo
3 = Ni de acuerdo ni en desacuerdo
4 = De acuerdo
5 = Muy de acuerdo

## Afirmaciones

U1. La interfaz del asistente es clara y fácil de comprender.

U2. Fue fácil identificar dónde escribir una consulta.

U3. Fue fácil realizar las consultas solicitadas.

U4. El sistema entrega una respuesta presentada de forma clara y legible.

U5. La información entregada por el asistente resulta útil para realizar las tareas.

U6. Los elementos de la interfaz son fáciles de localizar y utilizar.

U7. La retroalimentación del sistema durante la consulta resulta comprensible.

U8. En general, estoy satisfecho/a con la experiencia de uso del asistente.
